Completed

CareGap Intelligence

Analyzed preventive screening gaps using Snowflake SQL and Power BI, comparing blood pressure, breast, and colorectal screenings across clinics and regions.

Snowflake SQL Power BI Healthcare
Read the project overview

Question: Where are eligible screenings overdue or missing completed screening documentation?

Approach: Used SQL to identify eligible patient-screening combinations, calculate due dates, and assign screening statuses. Built a three-page Power BI report covering an overview, patient-level gaps, and clinic and region performance.

Results: Of 3,604 eligible screening records, 1,324 were overdue (36.7%). Another 1,612 had no completed screening with a valid date recorded. Blood pressure accounted for 61.5% of overdue records.

Project files: Documented the analysis with SQL scripts, validation queries, dashboard screenshots, the Power BI report, and source datasets.

Data: Synthetic patient and screening records with fictional clinics, analyzed as of October 1, 2026. Counts represent patient-screening combinations, not unique patients. Simplified training rules were used for this portfolio exercise.

This is an analytics exercise, not clinical guidance.
